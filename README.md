# 前言

《智能体应用开发：方法与架构》写给已有后端开发与架构经验、希望进入 AI 应用领域的读者。这是丛书第一卷：帮助你面对一个新需求，判断是否需要模型，选择控制方式，划清数据与动作边界，并用证据验证方案。

你已经熟悉接口、数据库、任务调度、权限和服务治理。这些经验仍然有用；新的困难在于，模型输出需要验证，动态行动需要约束，任务完成需要由外部结果确认。全书围绕三个问题展开：**哪些经验能直接用，哪些能力要新学，哪些习惯需要改变。**

## 本书的学习目标

学完一个主题，应能产出一份可以评审的设计，而不只是记住术语。读者需要能够解释：为什么规则程序不够，模型具体承担什么职责，为什么选择单次调用、工作流或智能体，失败时如何结束，以及什么证据会使自己改变选择。

本书假定读者了解接口、数据库、异常处理和基本测试，不要求先学习模型训练。正文聚焦方法与架构，框架操作和具体版本放在附录或配套代码中；深入的场景实战和框架实操留给后续分卷。

## 全书结构

全书共六篇、二十三章。第一篇建立需求判断方法；第二篇从模型接入和最小应用进入评测、工具、上下文与检索；第三篇讨论执行循环、任务状态、持久化、人工协作和多智能体取舍；第四篇通过六类场景练习架构推导；第五篇深化持续评测、发布验证、安全治理和成本控制；第六篇将这些决策汇集到运维助手的演进中。

场景篇用于比较架构选择，包含需求变化后的取舍，不承诺完整行业解决方案。综合案例采用教学场景，任何涉及外部状态变更的能力都需要独立的授权、结果核对与恢复设计。

建议先读[导读纲领](intro/skill-mapping.md)，再按[阅读路线](intro/determinism-vs-probabilistic.md)推进。每章开头把新问题与后端经验对应起来，末尾提供陌生需求练习及参考思路。先自己写出方案，再比较参考答案中的条件与备选方案。
