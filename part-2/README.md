# 第二篇 构建可验证的 AI 应用

从一次模型调用开始，本篇逐步构建能够生成告警分析报告的应用，再加入只读工具、上下文管理和知识检索。每增加一种能力，都需要说明它解决的问题，以及如何验证效果。

完成本篇后，你应能设计一个有清晰输入输出、证据来源、错误处理和基础评测的 AI 应用。
