# 附录 E 设计模板

本附录收录正文反复使用的三份空白模板。模板只列出必须回答的问题，填写完成不代表方案已经通过验证；每一格都应区分已确认的事实、项目约定与待验证的假设。

- [标准一页方案模板](one-page-design.md)：从需求推导第一版方案，共四组十二项。定义与示例见[第 2 章 2.4 节](../../part-1/02-architecture-matrix.md)，完整示范见[第一篇小结](../../part-1/reference-architecture.md)。
- [评测样例模板](evaluation-case.md)：记录一道评测题的输入、判定标准与试验结果。方法见[第 6 章](../../part-2/06-evaluation-basics.md)。
- [工具契约模板](tool-contract.md)：评审一项业务能力能否进入固定流程或交由模型提议。方法见[第 7 章](../../part-2/07-tool-integration.md)。
