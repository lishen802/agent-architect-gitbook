# 第三篇 设计可控的智能体系统

当任务需要根据证据动态决定下一步，固定流程可能不再足够。本篇讨论如何引入智能体执行循环，并用结构化状态、并发控制、持久化与人工审批约束执行过程。

完成本篇后，你应能说明任务如何启动、推进、暂停、恢复与终止，并识别外部操作带来的重复执行风险。
