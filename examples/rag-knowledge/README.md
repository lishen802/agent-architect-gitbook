# 第 9 章：带权限过滤的混合检索与证据检查

本目录用一个小型检索器演示第 9 章的几处控制点：权限预过滤、BM25 与向量检索、倒数排名融合（RRF）、证据适用性检查、引用核对、索引的更新与删除，以及检索指标。所有数据都是教学构造；程序不调用模型、不联网、不读取生产数据。

## 文件与职责

| 文件 | 内容 |
| --- | --- |
| [knowledge.py](knowledge.py) | 分词、段落与索引、权限过滤、BM25、向量检索、RRF、适用性检查、引用核对、按文档更新与删除、版本核对 |
| [metrics.py](metrics.py) | recall@k 与倒数排名 |
| [scenario.json](scenario.json) | 10 个段落（手册与事故复盘）、5 个带标注的问题、检索配置与源系统版本 |
| [answer_q3.json](answer_q3.json) | 针对 Q3 的一份候选回答，模拟模型输出的结构化陈述 |
| [demo.py](demo.py) | 对 5 个问题运行三种检索与适用性检查，输出结果与指标 |
| [report.json](report.json) | 本轮实际运行 `demo.py` 得到的输出 |
| [test_rag_knowledge.py](test_rag_knowledge.py) | 14 项关键行为测试 |

示例使用 Python 3.9 或更高版本的标准库，无第三方依赖。从仓库根目录执行：

```sh
python3 -B -m unittest discover -s examples/rag-knowledge -v
python3 -B examples/rag-knowledge/demo.py
```

预期结果：四个有标注的问题上，BM25、向量与混合检索的平均 recall@4 为 0.875、0.75、1.0，MRR 为 0.75、0.583、0.625；五个问题的状态（可回答或证据不足）全部正确。

## 检索规则

- **分词**：英文与数字按词切分，保留 `pay-504`、`max_pool_size` 这类标识符；中文取字符二元组。这只是没有分词器时的基线，真实索引应选用并评测适合语言的分析器。
- **权限与状态**：`visible` 要求段落的租户与认证上下文一致、访问组与用户组有交集、状态为 `published`。两种检索都在排序之前应用它（预过滤）。`vector(..., prefilter=False)` 演示后过滤：先取前 k 个再丢弃不可见段落，结果可能少于 k 个。
- **BM25**：参数 `k1 = 1.2`、`b = 0.75`，与 Elasticsearch 默认值相同；只返回至少共享一个词项的段落。文档频率与平均长度按整个索引计算，所以其他租户的段落会影响打分（但不会被返回）；隔离要求高时应按租户分索引。
- **向量**：`scenario.json` 中的八维向量是手写的教学数据，代替嵌入模型的输出；维度带名字只为便于阅读，真实嵌入没有可解释的维度。检索为精确余弦相似度，低于 `min_similarity`（0.5）的结果不返回。向量维度不一致时直接报错，对应“查询与段落必须由同一嵌入模型生成”。
- **RRF**：`score = Σ 1 / (k + rank)`，`k = 60`，名次从 1 开始；同分按段落 ID 排序，保证结果确定。

## 证据检查

`select_evidence` 按元数据排除不适用的段落：服务不符记 `service_mismatch`（`service` 为 `*` 的通用指南除外），写明适用大版本的手册与运行版本不符记 `version_mismatch`。没有剩余证据时状态为 `insufficient_evidence`。这项检查只排除明显不适用的材料，不判断段落是否真的回答了问题。

`check_citations` 检查结构化陈述中可由程序判定的部分：每条陈述都有引用；所引段落在本次上下文中；摘录逐字出现在段落里；陈述中的数字出现在摘录中。`answer_q3.json` 的第 5 条陈述能通过全部检查，却把“观察 10 分钟”说成了“一定能在 10 分钟内恢复”，这类错误需要语义判定。

## 索引同步

`apply_change` 按文档处理变更：更新时先删除该文档的全部旧段落，再写入新版本段落；删除时移除该文档的全部段落。`stale_chunks` 把索引中的文档版本与源系统的版本清单对比，列出版本不一致或源系统已删除的段落。示例只有一份内存索引；真实系统还要清除回答缓存、段落说明、评测样例等派生副本。

## 验证范围

测试覆盖：输出与保存的 `report.json` 及正文数字一致；分词保留标识符；标识符查询需要关键词检索、换说法需要向量检索；RRF 公式与确定性；无权限、草稿与其他租户段落在任何问题下都不被检索到，安全组用户可以看到安全复盘；后过滤返回少于 k 个结果；旧版本手册被排除；检索到但不适用导致证据不足；引用核对发现三类程序可查的错误，同时有一条错误陈述能通过程序检查；无引用的陈述被标出；更新替换全部段落；删除后两种检索都找不到；版本核对发现滞后；recall 对无依据的问题报错。

示例没有实现第 9 章的以下内容：段落切分与解析、隐藏内容检查、重排、查询改写、回答生成、冲突文档的呈现、权限变更的同步延迟。指标是五个教学问题上的结果，只说明机制，不代表任何检索方式在真实语料上的效果；真实效果需要按[第 9 章](../../part-2/09-rag-knowledge.md) 9.7 节在自己的任务集上评测。
