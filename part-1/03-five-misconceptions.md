# 第 3 章 AI 应用的设计原则与常见误区

> 本章为写作提纲，正文、示例与验证结果尚待补充。

## 3.1 以可验证的结果定义智能

从项目开始就保留代表性样例与失败样例；用结果和证据评价系统，而不是用回答是否流畅判断质量。

## 3.2 区分上下文、记忆与任务状态

说明对话历史、持久化记忆、结构化任务状态和推理服务 KV Cache 的不同用途与生命周期。

## 3.3 为模型输出设置执行边界

区分格式有效、语义正确与操作获准；通过校验、权限和事务管理约束外部动作。

## 3.4 让架构复杂度与问题匹配

从最简单的可行方案开始；依据评测结果决定是否增加检索、动态规划或多智能体协作。
