# 作者转型素材归档

此处只收集作者提供的真实经历，不自动生成个人故事。当前尚无经过作者确认的素材。归档负责人可由作者指定；本仓库不代表已经向任何人发送任务。

按三类归档：能直接迁移的经验、需要新学的能力、需要改变的习惯。素材可以有多个标签，但应指定主要类别。

每条记录复制以下字段：

- 日期与真实任务背景：
- 原先的理解和做法：
- 卡住时观察到的现象：
- 改变理解的证据或实验：
- 现在的理解及适用边界：
- 所属类别、可用章节：
- 涉及隐私或商业信息的脱敏处理：
- 作者确认状态：待确认／确认可公开。

“豁然开朗”只能说明个人理解变化，不能替代技术事实核验。正文可用作开篇“你可能也遇到过”，未经确认的素材留在作者工作区。
